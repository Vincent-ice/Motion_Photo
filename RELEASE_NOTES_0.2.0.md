# Motion Photo Maker 0.2.0

## Highlights

- PNG covers are now supported and converted safely into the JPEG primary image used by Motion Photo.
- Output aspect ratio can follow the selected cover image, including non-preset ratios.
- Long-video trimming now supports progressive precision zoom for accurately selecting short clips.
- New 4 / 6 / 9-grid Motion Photo collage mode for WeChat Moments-style image groups.
- Every grid tile now has its own 1:1 video editor with independent trim-in, trim-out, zoom and pan settings.

## Notes

- Grid projects split one source image into ordered square tiles and generate one Motion Photo per tile.
- Unedited grid videos still default to full duration and centered 1:1 crop.
- Development builds remain on the `develop` branch; official APKs are produced by the signed Release workflow.
